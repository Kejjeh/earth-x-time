# Agent guide

## What this is

Earth × Time is a single-file web page: a spatiotemporal knowledge graph with two clocks at right angles. **Earth-time** (4.54 Ga to now, log axis, real ICS ribbon) runs along the bottom. **Knowledge-time** (1650 to 2026, when we came to believe it) runs up the right edge and rewires the causal graph as it moves. The graph has 275 claims about 57 referents, wired by 52 edges. Vanilla JS and canvas 2D, no framework, no runtime network. Sibling of Human × Time. **Current state: working.** The build, the 141-check smoke test and every offline gate pass, and all 33 GitHub issues are closed. `README.md` explains every rule and its history, and "Known gaps" says what is and is not checked about sources. Read it before you change behaviour.

## Commands (all verified from repo root)

```bash
python tools/build.py                      # ~65s. Builds, then smoke-tests. Expect: "claims 275  referents 57  edges 52",
                                           #   "sources: 82 DOIs, 82 resolve ..., 37 claims content-checked",
                                           #   "141/141 checks passed", exit 0, and no git diff
python tools/validate_graph.py             # Expect: WARNINGS (0), ERRORS (0), exit 0. Rewrites src/graph.json in its compact form (no diff when clean)
python tools/check_sources.py --offline    # Expect: "regressions: all passed" and 82 / 82 / 37 / 179, "would lift under --write 0"
python tools/test_check_sources.py         # Expect: 18 "ok" lines, "regressions: all passed"
python tools/check_no_local_paths.py --all # exit 0 = no home-directory path in any tracked file
python -m http.server 8731                 # the "earth-x-time" config in .claude/launch.json; earth-x-time.html also opens off disk
```

- CI (`.github/workflows/tests.yml`) runs the five offline commands above, with Playwright, on every push to `main` and every PR, and fails on any diff after the build.
- `build.py` writes `earth-x-time.html`, `artifact.html` (body-only) and `index.html` (Pages). It does **not** run `validate_graph.py`; run that first when the graph changed. `--no-smoke` skips the browser gate (never as the final check).
- The smoke test needs `playwright` with Chromium (installed here). Without it `build.py` prints "skipping smoke test" and still exits 0, so check that the `141/141` line appears.
- Set `PYTHONUTF8=1` on Windows.
- **Network, not run during verification** (free APIs, but they rewrite committed data): `tools/ingest.py "<name>" ...` (Wikidata + Crossref, merges into `src/ingested.json`), `tools/check_sources.py` without `--offline` (Crossref), `tools/fetch_coast.py`, `fetch_ics.py`, `fetch_fonts.py`, `fetch_texture.py` (each rewrites one `assets/` file).
- `tools/apply_patch.py <patch.json>` and `tools/stage4_merge.py <output.json>` are dry runs; only `--write` touches `src/graph.json`.

## Architecture map

| File | Role |
|---|---|
| `src/20_core.js` | Constants and state; **`KT_MIN, KT_MAX` are declared here once** and `tools/knowledge_time.py` reads them |
| `src/30_model.js` | `queryFacts(axisState)` (the single query every view reads) and `resolve()` (a referent's date from competing claims, never stored) |
| `src/40_globe.js`, `50_chron.js`, `60_krail.js` | Globe, earth-time axis + ribbon, knowledge-time rail |
| `src/70_panel.js`, `75_search.js`, `76_url.js`, `80_boot.js` | Detail panel, search, URL hash state, wiring and boot |
| `src/graph.json` | The seed graph (referents, claims, edges), merged from clusters + `foundations.json` |
| `src/source_check.json` | Per-DOI Crossref record and the rule behind each lifted DOI |
| `src/ingested.json` | Review queue written by `ingest.py`; not in the graph until merged |
| `tools/validate_graph.py` | Gate: integrity, schema, coordinates, the product's promises. Mirrors `resolve()` line for line |
| `tools/smoke_test.py` | Headless-Chromium gate: desktop, 390×844 touch, both themes |
| `tools/check_sources.py` | Keeps "DOI resolves" and "content checked" apart; lifts DOIs only by stated rules |
| `tools/apply_patch.py`, `stage4_merge.py` | The only tools that merge authored content into the graph |
| `.claude/workflows/author-status.js` | Stage-4 workflow: authors dating claims and status timelines for ingested referents, then an adversarial citation check |

## Conventions and gotchas

- **Edit `src/`, never the built files.** The three HTML files are generated by `tools/build.py` and committed with the `src/` change that produced them.
- **One query path.** Every view reads `queryFacts()`. Positions are always recomputed by `resolve()`; never store one.
- **`validate_graph.py` must ask the page's question.** Its `resolve()` mirrors `src/30_model.js`; change both together, and the smoke test pins them to the same figures.
- **"DOI resolves" and "content checked" are different facts.** A resolving DOI never sets `source_status: "checked"`. Never complete a citation from author, year and journal alone.
- **A statement with no resolvable reference produces no claim.** Status timelines (proposed → contested → consensus) are authored, never inferred from citation counts.
- **Move knowledge-time bounds only in `src/20_core.js`.** Nothing else may type them out.
- `apply_patch.py` names a `.claude/workflows/author-causal-edges.js` workflow that is not in the repo; only `author-status.js` is.
- **The pre-commit hook** (`.githooks/`, armed here) rejects any staged absolute home-directory path. Never write one into a doc or commit, and never use `--no-verify`. Use placeholders such as `/home/you/...`.
- No secrets in this repo.
- **Do not read into context**: `index.html`, `earth-x-time.html`, `artifact.html` (~780 KB each, built), `src/graph.json` (~330 KB, one line; query it with `python -c` or `jq`), `assets/*.txt`, `assets/fonts.css`, `preview.jpg`.

## Before you finish any task

1. If the graph changed: `python tools/validate_graph.py` → `ERRORS (0)`, exit 0.
2. `python tools/check_sources.py --offline` → `regressions: all passed`.
3. `python tools/build.py` → `141/141 checks passed`, exit 0. If you added smoke checks, the count goes up; update this file and the README.
4. `git diff --stat` → only files you meant to change. A docs-only change must leave `src/`, `assets/` and the three HTML files untouched.

## Model routing

Safe for Sonnet: README/CLAUDE.md edits; CSS, copy and contrast tweaks; adding a smoke check for existing behaviour; rebuilding; filing issues.

Escalate to Opus: `queryFacts` / `resolve()` and the mirrored resolver in `validate_graph.py`; any change to graph content (claims, dates, status timelines, DOIs, `source_status`); `check_sources.py` lift rules; ingest and merge tools; knowledge-time bounds.
